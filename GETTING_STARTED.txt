🎓 KEY ALGORITHMS:

1. NDVI Calculation
   NDVI = (NIR - RED) / (NIR + RED)
   Range: -1 to 1 (higher = more vegetation)

2. Change Detection
   Compare NDVI before/after
   Threshold-based deforestation detection

3. Carbon Loss
   Carbon Loss = Area × Carbon Density
   CO2 = Carbon Loss × 3.67

4. Time-Series Forecasting
   ARIMA(p,d,q) or SARIMA(p,d,q)(P,D,Q,s)
   Trend analysis and future predictions

5. Deep Learning (Optional)
   U-Net: Pixel-wise segmentation
   Siamese: Before/after comparison

❓ TROUBLESHOOTING:

Problem: Import errors
Solution: pip install -r requirements.txt

Problem: TensorFlow issues
Solution: Use CPU version: pip install tensorflow==2.10.0

Problem: Streamlit not starting
Solution: streamlit cache clear && streamlit run dashboard_app.py

Problem: Plots not showing
Solution: Add import matplotlib; matplotlib.use('TkAgg')

Problem: Out of memory
Solution: Reduce BATCH_SIZE in config.py
